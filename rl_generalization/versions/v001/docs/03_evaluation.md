# 위치 일반화 평가 초안

## 공간과 커리큘럼

작업 영역은 로봇 베이스 좌표로 정의하고 실제 도달성·카메라 가시성·충돌 여유를 측정한 후 경계를 결정한다. 영상만으로 cm 범위를 정하지 않는다.

L0: 기존 신발 위치·방향에서 기준 성능.
L1: 같은 신발, 같은 방향, 근처 위치 변화.
L2: 지정 작업 영역의 여러 위치. 예비 설계는 3×3 위치 구역이며 크기는 실측 후 결정.
L3: 위치 + 신발 방향. 두 신발의 순서·간격·겹침 여부를 따로 정의.
L4: 상자 또는 정차 트레이 위치 변화. 신발 위치 실험과 독립 축.
L5: A→B 연속 실행, 실제 A 종료 배치를 B가 처리. 사람이 상자를 정렬하지 않음.

각 단계의 통과 목표, 평가 횟수와 예산은 실험 시작 전 기록한다. 본 초안에 검증되지 않은 임계값을 확정하지 않는다.

## 비교군

A: 고정 위치 기존 ACT.
B: 다위치 추가 시연으로 학습한 ACT.
C: B와 같은 기반 ACT + Residual RL.
D(선택): A + Residual RL. 넓은 초기 위치 변화에서 기본 정책 범위의 영향을 검증.
E(선택): 위치 추정+기하 접근+학습 접촉 제어.

B/C에서 재예측 주기, 제어 제한, 입력 센서, 평가 조건을 맞춘다. 총 추가 인간 시간/로봇 상호작용 시간/시연 수/학습 시간을 모두 보고한다. 자료 수가 다르면 비용 대비 곡선과 동일 예산 지점을 제시한다.

## 데이터 분리

훈련: 여러 위치를 포함하고 실제 좌표를 기록. 검증: 임계값/하이퍼파라미터 선정. 테스트: 사전에 고정한 미사용 좌표·수집 세션. 같은 episode의 인접 프레임이 train/test에 걸치지 않도록 한다.

훈련 범위 안 미사용 좌표(보간)와 범위 밖 좌표(외삽)를 별도 보고한다. 새로운 신발·조명은 별도 시험이다. 평가 순서를 섞고 모델 간 동일한 시작 배치 목록을 사용하되 실제 배치 오차를 기록한다. 평가에서는 학습/버퍼 업데이트를 하지 않는다.

## 결과

위치별 무개입 성공률 지도, 방향별 성공률, 원래 위치 성능 유지, A/B/연속 성공률, 파지·운반 낙하·투입·닫기·적재 실패 분포, 개입/리셋 시간, 시도 수, 완료 시간, 제어 지연을 보고한다. 성공한 실행만의 시간과 전체 실패·timeout 현황을 함께 제시한다.

성공률은 성공수/시도수와 신뢰구간을 함께 보고한다. 예비 실험 후 필요한 표본 수를 결정하고 소수 반복의 상승을 확정적 개선으로 주장하지 않는다. 학습 seed와 반복 평가 episode를 구분하며 seed별 결과를 유지한다. 공간/세션/seed의 의존성을 무시한 프레임 단위 통계는 사용하지 않는다.

학습 보상 판정기와 독립적인 영상 검토로 최종 성공을 판정한다. 판정 불가는 별도 기록하고 사후 임의 제외하지 않는다. 자동 재시도 포함 성공률과 첫 시도 성공률을 분리한다.
