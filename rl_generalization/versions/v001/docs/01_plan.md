# 위치 일반화 판단 및 구현 계획

## 사실과 미확인 사항

사용자 보고: IL 성공률 약 85% 이상, 신발 시작 위치 고정. 작업별인지 연속 실행인지와 분모는 미확인이다. move_in은 상자를 집어 들어 운반하고 물류로봇에 적재하는 작업이다. 영상은 단일 실행의 외부 촬영이며 ACT의 top/wrist 입력 영상과 동일하지 않다.

이전 대화에서 HF 지정 커밋의 ACT 설정을 확인했다: 6차원 상태/행동, top/wrist 640×480, chunk_size=100, 모델 n_action_steps=100, MEAN_STD. 실행 스크립트는 재예측 주기를 덮어쓸 수 있으므로 실제 실행 설정을 별도로 기록한다. 이번 영상에서 모델 해시나 실행 주기를 증명한 것은 아니다.

## 핵심 답변

RL은 여러 시작 위치에서 상호작용하고 보상을 받도록 구성하면 위치 변화 대응을 학습할 수 있다. 그러나 RL 자체가 위치 불변성을 보장하지 않는다. 현재 고정 위치에서의 85%는 새 위치 성능을 의미하지 않는다. 영상 입력이 있다고 물체 위치를 제어에 충분히 활용한다고 단정할 수 없다. 고정된 궤적에 의존하는지 위치 이동 평가로 확인해야 한다.

목표는 '어디든'이 아니라 '카메라로 관측되고 충돌 없이 도달·파지 가능한 지정 작업 영역 안에서, 정해진 신발 종류와 자세 범위에 대해 성공'으로 정의한다. 테이블 밖, 팔 도달 밖, 가림, 뒤집힘, 겹침, 미지 신발은 서로 다른 일반화 문제다.

## 권장 경로

1. 현재 ACT의 위치별 성공률 지도 측정: 상자와 트레이 고정, 신발 위치만 변화. 단일 대상부터 시작하고 영상의 두 신발 조건으로 확장한다.
2. 기존 위치 근처뿐 아니라 지정 영역의 다양한 위치·방향에서 시연을 추가한다. 원래 데이터와 혼합해 재학습하여 원래 성능도 유지되는지 본다.
3. 넓은 영역으로 접근·집기가 가능한 ACT를 기준 정책으로 확립한다.
4. 제한된 residual SAC로 파지 접촉·투입·뚜껑 닫기·안착 오차를 개선한다. 작은 residual이 큰 공간 이동까지 해결한다고 가정하지 않는다.
5. 작업 A 종료 상태를 그대로 B에 넘기는 연속 실행 평가로 통합한다. 상자와 물류로봇 위치 변화는 신발 위치 변화와 분리해서 추가한다.

순수 온라인 RL로 접근을 처음부터 배우는 것도 가능하나 고정 위치 정책에서 먼 위치의 sparse reward를 얻기까지 실물 수집 비용이 커질 수 있다. Offline RL만으로 관측하지 않은 먼 위치의 복구 행동을 얻는다고 주장하지 않는다. 영상 색·크롭 증강은 실제 관절 동작과 보상이 달라지는 물리적 위치 변화 데이터의 대체가 아니다.

## 관측 설계 선택

A. 기존 top/wrist RGB + 관절: 다위치 시연으로 시각 기반 정책을 확장. 우선 기준선.
B. RGB + 관절 + 목표 신발/상자/트레이의 상대 위치·방향: 명시적 위치 정보를 추가하는 비교군. 좌표 입력 차원이 달라져 기존 ACT를 그대로 쓸 수 없고 구조·정규화·재학습이 필요하다.
C. 위치 추정으로 파지 전 자세까지 접근하고 학습 정책으로 접촉 수행: 공학적 비교군. 전체 제어가 end-to-end RL이라고 부르지 않는다.

YOLO bbox 중심은 3D 파지점이 아니다. 카메라 보정, 깊이 또는 평면 가정, 신발 높이·잡을 부위·그리퍼 접근 자세가 필요하다. 평면 homography는 그 평면 위 점에만 맞으며 신발의 솟은 파지점 높이를 자동 복원하지 못한다. 기존 카메라를 유지하고 별도 파이프라인에서 ROI를 쓸 수 있으나 ACT의 입력 전처리를 임의 변경하지 않는다.

## 구현 단위와 통과 기준

- 환경 어댑터: reset/step/관측/실제 전송 행동/종료 사유. 학습 중 매 episode 물체 초기화 필요; 초기엔 수동 리셋.
- 실행 계층: ACT 역정규화 후 로봇 단위에서 보정, 관절별 제한 적용. zero-residual이 기존 실행과 일치하는지 확인.
- 관측·기록: 원본 센서 시간, 기본 행동, residual 요청, 제한 후 명령, 개입, 다음 관측, 단계, 큐 진행 정보 보존. 학습 행동의 의미를 일관되게 정의.
- 데이터 변환: 기존 관절 목표 action을 residual로 그대로 넣지 않는다. 필요하면 동일 실행 규칙의 ACT 기본 행동과 차이를 산출하고 단위·시각·범위를 검증.
- 성공 판정: 실제 물체 파지/투입/닫힘/팔 퇴피 후 안착. 그리퍼 닫힘과 물체 파지를 구별. 두 신발 모두 투입인지 명시.
- 보상: 처음엔 사람 판정 sparse terminal reward로 시작 가능. 중간 단계 보상은 최초 달성에만 주고 반복 획득을 막는다. timeout과 task termination을 구분한다.
- 학습·평가: 정책/데이터/보상기/카메라 보정/시드/행동 주기 버전 고정. 한 노드만 최종 로봇 명령을 전송하고 사람 개입을 표시한다.

## 연구 질문 수정

고정 배치에서 남은 15% 개선보다 '고정 위치 ACT를 제한된 추가 수집 예산으로 다위치 작업에 확장할 때, 다위치 IL과 다위치 IL+Residual RL의 비용·성공률·공간 일반화 차이는 무엇인가?'를 주 질문으로 제안한다. 새 알고리즘이라는 주장은 하지 않는다.
