# v002: 새 집기 정책과 실물 연결 계획

## 수정 근거

사용자 확인: 고정 배치 ACT 성공률 약 85% 이상. 두 신발의 위치를 바꾸면 파지하지 못하며 지터와 헛집기가 심하다. 따라서 기존 ACT+작은 residual을 공간 일반화의 주 경로로 삼지 않는다. 원인 진단 후 별도의 위치 대응 파지 정책을 만든다. 새 다위치 시연을 필수 전제로 하지 않는다.

## 정책 결정

첫 과제는 신발 한 개, 방향 고정, 접근→파지→들기→유지다. 시작 위치를 episode마다 바꾸며 실제 시도에서 경험을 수집할 계획이다. 1차 후보는 위치 기반 SAC MLP, 제한된 말단 xyz 변화와 그리퍼 제어다. 이는 새 전체 파지 정책이며 ACT residual이 아니다. OMX IK와 가용 자세를 검증한 뒤 실제 action 차원을 확정한다. 신발 yaw까지 바꾸는 정책은 현재 구현하지 않았다.

지금 테스트 환경은 ee/object/상대 좌표, 그리퍼, 부착 여부, 유지 시간, 이전 행동을 입력으로 사용한다. 실물에서는 목표 파지점, 파지 여부, 신선도 등을 실제 센서로 얻어야 하며 oracle state를 사용할 수 없다. occlusion/관측 누락에는 중단·재관측 처리가 필요하다. 현재 코드는 실물 관측 파이프라인을 구현하지 않는다. RGB 기반 SAC는 위치 추정이 불가능할 때의 다른 경로이며 현재 구현과 구별한다.

SAC의 초기 탐색은 실물에서 무작위 action을 그대로 내보내지 않는다. 접근 가능한 좁은 영역, 검증된 접근 제어와 reset, IK/관절/속도 제한을 먼저 만들고 초기 경험 수집 전략을 확정한다. toy의 learning_starts 동안 uniform exploration은 소프트웨어 검증용이다.

## 가상환경은 필요한가?

Gymnasium 환경은 실물도 감쌀 수 있으므로 물리 시뮬레이터는 필수가 아니다. 실제 접근 경로: 센서→실물 환경→SAC→제어기→센서. 시도마다 사람이 물체를 복원하고 성공을 표시할 수 있다.

현재 ToyGraspEnv는 학습·저장·평가 파이프라인 테스트용이다. 정답 좌표, 거리 임계값 부착, 순간 낙하를 사용한다. OMX 관절/IK, 신발 접촉·변형·마찰, 카메라, 충돌을 재현하지 않는다. toy checkpoint는 실물에 배포하지 않는다.

MuJoCo/Isaac 등의 물리 시뮬레이터는 실물 reset 비용이 너무 크거나 병렬 탐색이 필요할 때 선택한다. 그 경우 실제 URDF/그리퍼, 신발 collision/질량/마찰, 센서 및 지연, domain randomization과 sim-to-real 검증이 별도 작업이다. 현 단계에는 simulator 구축을 선행조건으로 두지 않는다.

## 단계와 통과 기준

0. 지터 진단: 고정/변경 배치에서 ACT raw/역정규화/제한 후 목표, 실제 관절, 센서 시각, chunk 갱신 시각 기록. 정책 출력 진동과 제어 추종 진동을 구별. 주기를 줄였다는 이유만으로 개선을 선언하지 않음.
1. 실물 접근 연결: 좌표 보정과 파지 후보 위치, IK 도달성, 제어 단위, 정지 및 운영자 reset 검증. 학습 없이 명령/관측 로그 확인.
2. 한 신발 파지 정책: 좁은 시작 분포부터 RL 실행 경험 수집. 파지 성공은 그리퍼 닫힘이 아니라 실제 들림/유지로 판정. 필요하면 사람이 보상 제공.
3. 공간 확대: 위치별 실패율, 원래 위치 성능, 인간 리셋 시간을 기록. 실패만 반복되면 탐색/관측/보상을 수정하며 확대 중지.
4. 투입: 새로운 파지 자세에서 기존 전체 ACT의 중간부터 실행하는 것은 보장되지 않음. handoff 상태를 검증하거나 새 투입 정책을 별도로 학습.
5. 두 신발: target ID를 episode/집기 동안 고정; 하나 투입 후 다음 대상 선택. YOLO가 있는 것만으로 3D 파지점이 얻어지지 않음.
6. 닫기/싣기: 기존 번들을 연결하되 실제 물체 상태 및 arm-clear를 확인. 개별 성공과 연속 성공 별도 측정.

## 실물 실험 비교군

원래 ACT, 재예측 주기 조정 ACT, 새 파지 정책+검증된 후속 실행. 추가 시연 IL은 수집 가능할 때 선택 비교군이다. 같은 위치/시드 목록, 시도 수, 무개입 성공률, 시간, 실패 단계, 인간 시간과 신뢰구간을 보고한다. toy 결과를 이 비교 표에 넣지 않는다.
