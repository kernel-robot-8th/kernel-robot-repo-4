# map_view_pc

Pinky 로봇으로 만든 지도(`cobot_map_v6`)와, 지도 위에서 map 좌표(m)를 확인하고 순찰 waypoint 좌표를 정할 때 쓰는 웹 뷰어입니다.

## 주요 기능

- **실시간 좌표 표시**: 마우스를 올리면 이미지 픽셀, map 좌표 `(x, y)`(m), occupancy(free / occupied / unknown)가 표시됩니다.
- **클릭으로 좌표 기록**: 지도를 클릭하면 `P1`, `P2`, … 순서로 점이 찍히고 map 좌표와 픽셀 좌표가 목록에 쌓입니다. 점별 `삭제`, 전체 `모든 점 지우기` 버튼이 있습니다.
- **그리드**: 0.05 m(파랑)·0.2 m(빨강, 좌표 라벨 포함) 그리드와 map 원점 `(0, 0)` 표시. `그리드 on/off` 버튼으로 끌 수 있습니다.
- **지도 정보 표시**: 이미지 크기, 해상도, origin, x/y 범위를 상단에 보여 줍니다.
- **지도 불러오기**: 처음엔 빈 화면이고, `지도 불러오기` 버튼이나 드래그 앤 드롭으로 `.yaml` + `.pgm` 을 불러옵니다.
- **라이트/다크 모드**: 브라우저/OS 설정을 따라 자동 전환됩니다.

## 설치 방법

설치할 것이 없습니다. 최신 웹 브라우저만 있으면 됩니다. 이 저장소를 받아 두고 `src/cobot_navigation/map_view_pc` 에서 엽니다.

```bash
cd <워크스페이스>/src/cobot_navigation/map_view_pc
```

## 실행 방법

**로컬에서 열기** (`map_view_pc/` 폴더에서)

```bash
xdg-open pinky_map_viewer.html      # Linux
open pinky_map_viewer.html          # macOS
start pinky_map_viewer.html         # Windows (cmd)
```

파일을 더블클릭해서 브라우저로 열어도 됩니다. 서버는 필요 없습니다.

### 지도 불러오기

처음 열면 **빈 화면**입니다. 지도를 불러오는 방법은 두 가지이며, 둘 다 `.yaml` 과 `.pgm` 을 **함께** 고릅니다(Ctrl+클릭).

1. **지도 불러오기 버튼**: 파일 선택 창에서 `map_view_pc/maps/` 로 가서 yaml+pgm 을 고릅니다.
2. **드래그 앤 드롭**: 파일 관리자에서 yaml+pgm 을 선택해 뷰어 화면에 끌어다 놓습니다.

선택 창이 처음부터 `maps/` 에서 열리게 경로를 지정하는 것은 웹 페이지가 할 수 없습니다. 대신 Chrome 계열은 이 버튼으로 마지막에 연 폴더를 기억하므로, **처음 한 번 `maps/` 를 열어 두면 다음부터는 그 폴더에서 열립니다.**

지원 형식은 바이너리 PGM(P5, 8bit)이고, 해상도·origin 은 yaml 에서 읽습니다. yaml 의 `image:` 와 이름이 같은 pgm 이 함께 선택되어야 합니다. 지도를 바꾸면 기록한 점은 초기화됩니다.

## 사용 예시

1. 뷰어를 열고 지도 위에서 마우스를 움직여 원하는 위치의 map 좌표를 확인합니다.
2. 순찰 지점으로 쓸 위치를 클릭합니다. 목록에 아래처럼 기록됩니다.

   ```
   P1 — map: (0.650, 0.150) m   px: (82, 14)
   ```

3. 기록된 `map` 좌표(m)를 순찰 노드(`cobot_pinky_patrol`)의 `config/pinkyN.yaml` 의 `points` 에 옮겨 적습니다.
   - 지점 좌표는 코드가 아니라 YAML 파라미터이므로 코드 수정 없이 바뀝니다. 노드를 다시 실행하면 반영됩니다.
4. 지도에 표시된 `P1`, `P2` 같은 번호는 뷰어에서 클릭한 순서일 뿐이고, 순찰 노드의 지점 이름(P1~P7)과는 관계없습니다.

## 프로젝트 구조

```
map_view_pc/
├── README.md                # 이 문서
├── pinky_map_viewer.html    # 좌표 뷰어 (단일 파일, 서버 불필요)
└── maps/
    ├── *.pgm                # 기본 지도 이미지 (1개)
    └── *.yaml               # 지도 메타데이터 (resolution, origin, threshold) (1개)
```
