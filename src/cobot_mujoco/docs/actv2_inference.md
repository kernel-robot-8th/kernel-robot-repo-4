# 1026 v2 학습 모델 추론 명령

실행기: `/home/team11/il_ws/run_actv2.sh`. 이전 1024 데이터용 `run_act044.sh`와 모델 번호가 다르다.
LeRobot 0.4.4와 신규 1026 데이터 모델을 사용한다. Init 이동은 기본 OFF다.
번호 1~25는 신규 실험이며 26~28은 동일 데이터의 기존 40k 비교 모델이다.
전류 포함은 실시간 그리퍼 Present_Current를 읽어 상태 마지막에 추가한다. 입력7·출력6이다.
전류 미포함은 원본 OMX의 상태6·출력6이다. 로봇 타입은 모델 입력 크기로 자동 선택한다.

```bash
cd ~/il_ws
./run_actv2.sh list

# CPU에서 모델·전처리·후처리 로딩만 확인. 장치 연결 없음.
./run_actv2.sh check 7

# 실제 명령 미리보기: 로봇·카메라 연결 없음.
./run_actv2.sh run 7 --action-steps 1 --temporal-ensemble --no-relative-target --duration 50 --dry-run

# 실제 구동: 신규 전류 포함·배치8·chunk32
./run_actv2.sh run 7 --action-steps 1 --temporal-ensemble --temporal-ensemble-coeff 0.01 --no-relative-target --duration 50

# 실제 구동: 신규 전류 미포함·배치16·chunk32
./run_actv2.sh run 4 --action-steps 1 --temporal-ensemble --temporal-ensemble-coeff 0.01 --no-relative-target --duration 50

# 실제 구동: 기존 40k·전류 미포함·배치8·chunk32
./run_actv2.sh run 26 --action-steps 1 --temporal-ensemble --temporal-ensemble-coeff 0.01 --no-relative-target --duration 50
```

`--step` 생략 시 해당 실험의 검증 MAE 최저 저장본을 선택한다.
`--step 5000`처럼 실제 저장된 step을 직접 지정할 수 있다. `checkpoints 번호`로 목록을 확인한다.
아직 검증 전인 중간 저장본은 최신 완전 저장본으로 선택하고 미검증이라고 표시한다.
`--action-steps 1`은 추론 실행 구간, `--temporal-ensemble-coeff 0.01`은 앙상블 가중 계수다.
`--no-relative-target`은 목표 변화량 제한을 해제한다. 종료 시 드라이버는 토크를 해제한다.

## 일시정지와 재개

실물 추론을 위해 학습을 사용자 요청으로 일시정지했다. 자동 재개하지 않는다.
추론 프로세스가 종료된 다음 아래 명령으로 마지막 체크포인트부터 재개한다.

```bash
systemctl --user start omx-actv2-training.service
```

30분 알림은 일시정지 상태를 표시한다. 이번 명령 준비 과정에서는 로봇을 구동하지 않았다.
CPU 모델 로딩, 원본 0.4.4 CLI 파싱·factory 선택, 가짜 모터의 상태 순서와 행동 차원,
녹화 프레임의 GPU 추론을 확인한다. 실물 성공률을 검증했다는 뜻은 아니다.
