# 학습 파라미터 설명서

> **1차 실험 보관 문서입니다.** 현재 재학습의 수집 역할·공식 LeRobot 기본 ACT·실제 파라미터는 [새 재학습 설명서](retraining.md)를 확인하세요. 1차의 ‘나중 데이터 전체를 최종 테스트’로 둔 해석은 현재 프로토콜에 적용하지 않습니다.

이 문서는 완료된 실험 설정과 실제 실행 코드를 기준으로 생성했습니다.

- 시연 2·4·8건은 녹화 수이며 박스 개수가 아닙니다. 학습·검증 영상의 박스는 2개입니다.
- 12가지 설정 × 시드 3개 = 36개 실험이며 자동 설정 탐색은 사용하지 않았습니다.
- 실험 안에서 lr은 고정했고, 가중치는 AdamW로 갱신했습니다.

## 실제 변경 파라미터

| 키 | 이름 | 실제 값 | 기능 | 적용·해석 |
|---|---|---|---|---|
| `action_steps` | 재예측 전 실행 길이 | 10, 5 | 예측한 행동을 몇 스텝 실행한 뒤 새 관측으로 다시 예측할지 정합니다. | 시뮬레이션 제어. 5·10스텝은 약 0.17·0.33초입니다. 학습 손실이나 가중치 갱신에는 직접 쓰지 않습니다. |
| `augmentation` | 영상 증강 | 끔, 켬 | 학습 영상의 밝기·대비·위치를 무작위로 바꿉니다. | 학습 관측만. 밝기·대비 배율 0.8~1.2, 가로·세로 이동 각 -3~3픽셀입니다. 이동 시 가장자리는 반대편으로 돌아옵니다. |
| `batch_size` | 한 번의 갱신에 쓰는 표본 수 | 24 | 관측 프레임과 해당 미래 행동 묶음을 모아 한 번에 학습합니다. | 학습. 모든 실험에서 24로 고정했습니다. 에피소드 끝의 마지막 작은 배치도 사용했습니다. |
| `dim_feedforward` | ACT 중간 신경망 크기 | 1024, 512 | 변환기 내부 순방향 신경망의 중간 폭입니다. | ACT만 사용. 512·1,024를 비교했습니다. 증가하면 용량·계산량이 커집니다. |
| `dim_model` | ACT 내부 특징 크기 | 128, 256 | ACT가 관측과 행동을 표현하는 벡터의 폭입니다. | ACT만 사용. 128·256을 비교했습니다. 상태 MLP·CNN 설정에 남아 있는 값은 실제 구조에 적용되지 않습니다. |
| `dropout` | 무작위 활성값 제외 비율 | 0.1, 0.2, 0.25 | 학습 중 일부 활성값을 무작위로 제외해 특정 특징 의존을 줄입니다. | MLP·CNN 출력부 / ACT 변환기. 0.1은 10%, 0.25는 25%입니다. 평가할 때는 꺼집니다. |
| `family` | 모델 종류 | act, cnn, state | state는 관절값만, cnn·act는 관절값과 두 카메라 영상을 사용합니다. | 모델 입력·구조. 상태 모델은 물체 개수나 위치를 영상으로 볼 수 없습니다. |
| `horizon` | 미래 행동 예측 길이 | 16, 32, 64 | 한 번에 예측하는 미래 관절 목표값의 개수입니다. ACT의 chunk_size에 대응합니다. | 예측 출력·학습 목표. 30Hz에서 16·32·64스텝은 약 0.53·1.07·2.13초입니다. |
| `lr` | 학습률 | 0.0001, 0.0003, 0.001, 0.00005 | AdamW가 가중치를 갱신할 때 사용하는 기본 이동 크기입니다. | 모든 학습 가중치. 크면 빠르게 변하지만 불안정할 수 있고, 작으면 더 많은 학습이 필요할 수 있습니다. |
| `max_steps` | 최대 가중치 갱신 횟수 | 30000 | 한 실험에서 허용하는 최댓값입니다. 실제 실행 횟수와 다릅니다. | 학습 종료 조건. 30,000으로 고정했고, 실제 종료 단계는 각 실험 기록에서 확인합니다. |
| `min_steps` | 조기 종료 전 최소 단계 | 1000 | 개선이 없더라도 이 단계 전에는 조기 종료하지 않습니다. | 학습 종료 조건. 1,000으로 고정했습니다. 전체 시간 상한은 별도로 적용됩니다. |
| `patience` | 개선 대기 횟수 | 10 | 최고 검증 오차가 충분히 개선되지 않은 검증 횟수입니다. | 조기 종료. 10회로 고정했습니다. 개선 인정 기준은 기존 최고값보다 0.005를 초과해 낮아지는 것입니다. |
| `seed` | 난수 시드 | 17, 42, 97 | 초기 가중치·표본 순서·증강·학습 녹화 부분집합을 재현하기 위한 번호입니다. | 학습 반복. 17·42·97입니다. 새로운 실물 녹화나 독립 현장 시도 3건을 추가한 것은 아닙니다. |
| `state_noise` | 관절 관측 노이즈 | 0, 0.03 | 정규화한 관절 입력에 평균 0인 정규분포 노이즈를 더합니다. | 학습 관측만. 0 또는 표준편차 0.03입니다. 0.03도나 원래 관절 단위 0.03을 뜻하지 않습니다. |
| `train_episodes` | 학습 시연 수 | 2, 4, 8 | 학습에 쓰는 독립 녹화 수입니다. 박스 개수와 다릅니다. | 데이터. 2·4·8건을 비교했습니다. 각 학습 영상은 박스 2개 조건입니다. |
| `validation_every` | 검증 간격 | 250 | 몇 번 가중치를 갱신한 뒤 학습·검증 오차를 기록할지 정합니다. | 검증. 250스텝마다 확인합니다. 시작·재개 직후 1스텝에서도 한 번 확인했습니다. |
| `weight_decay` | 가중치 감쇠 | 0.0001, 0.01 | AdamW가 큰 가중치를 억제하는 정도입니다. | 모든 학습 가중치. 값을 키우면 과적합 완화를 기대할 수 있지만 학습 부족을 만들 수도 있습니다. |

## 고정 설정

| 항목 | 실제 값 | 설명 |
|---|---|---|
| 최적화 방식 | AdamW | 모든 학습 가중치를 같은 lr·weight_decay로 갱신했습니다. ACT 기본 최적화 설정의 별도 이미지 인코더 학습률은 사용하지 않았습니다. |
| AdamW 기본 계수 | β1=0.9 / β2=0.999 / ε=0.00000001 | 갱신 방향과 크기의 이동 평균·수치 안정성 계수이며 바꾸지 않았습니다. |
| 학습률 변화 방식 | 실험 안에서는 고정 | 학습률 스케줄러·워밍업·자동 학습률 탐색을 사용하지 않았습니다. 실험 사이에서만 사전 지정한 lr 값을 바꿨습니다. |
| MLP·CNN 출력부 폭 | 256 → 256 | 상태 모델과 CNN 모델의 출력 신경망 중간 폭은 고정했습니다. |
| CNN 영상 인코더 | 합성곱 4개, 채널 24·48·64·64 | 두 카메라가 인코더를 공유하고 각 128차원 특징을 얻습니다. 이 CNN은 ImageNet 사전학습 모델이 아닙니다. |
| ACT 영상 인코더 | ResNet18 / ImageNet 초기값 | 이미지 인코더는 사전학습 가중치로 시작했고 학습 중 함께 갱신했습니다. |
| ACT 변환기 층·헤드 | 인코더 2층·디코더 1층·헤드 8개 | 전체 ACT 실험에서 고정했습니다. |
| ACT 잠재 변수 | VAE 사용 / 잠재 크기 32 / 인코더 2층 | 학습할 때 시연의 잠재 표현을 사용합니다. 검증·추론은 잠재값 0으로 수행했습니다. |
| ACT KL 가중치 | 10 | 행동 예측 오차와 잠재 분포 규제 항의 균형입니다. 이번 실험에서는 바꾸지 않았습니다. |
| 손실 함수 | 유효 미래 행동의 L1 / ACT는 KL 항 추가 | 에피소드 끝을 넘는 패딩은 행동 손실에서 제외합니다. |
| 그래디언트 제한 | 전체 노름 10 | 급격히 큰 가중치 갱신을 줄이도록 역전파 뒤에 적용했습니다. |
| 입력 영상 | 카메라 2대 / RGB 128×96 | 원본 640×480을 축소했습니다. 기존 현장용 640×480 모델과 입력 조건이 다릅니다. |
| 관절 입력·출력 | 현재 관절값 6개 → 목표 관절값 6개 | 팔 관절 5개와 그리퍼 1개입니다. 전류·속도·EE 포즈 보조 항목은 이번 정책 입력에 사용하지 않았습니다. |
| 관절·행동 정규화 | 각 실험의 학습 녹화 평균·표준편차 | 검증·테스트의 통계는 섞지 않았고 표준편차는 최소 1로 제한했습니다. |
| 영상 정규화 | ImageNet 평균·표준편차 고정 | 카메라 입력에 같은 정규화 기준을 적용했습니다. |
| 관측 표본 간격 | 학습 3 / 학습 오차 확인 24 / 검증 12 / 테스트 6프레임 | 이는 관측 시작점의 간격입니다. 미래 행동 목표는 원래 30Hz 간격을 유지합니다. |
| 수치 연산 | FP32 / 행렬곱 정밀도 high / AMP 미사용 | 혼합 정밀도 학습은 사용하지 않았습니다. |
| 체크포인트 선택 | 앞 10개 미래 행동의 녹화별 평균 MAE | chunk 길이가 달라도 같은 10스텝으로 비교했습니다. 검증이 가장 좋은 체크포인트와 마지막 체크포인트는 다릅니다. |
| 시간 상한 | 실험당 1,500초 / 전체 최대 12시간 / 마무리 30분 확보 | 12시간을 반드시 채우는 방식이 아닙니다. 각 실험의 실제 종료 사유와 단계는 기록에서 확인합니다. |
| 시뮬레이션 비교 | 제어 30Hz / 회당 50초 / 조건 6개 / 시드 3개 / 제어 방식 2개 | 학습 설정과 별도입니다. 기존 기본 장면의 박스 3개 설정 오류는 정정 절을 확인하세요. |

## 해석 시 주의

regularized는 학습률·감쇠·dropout을 함께 바꾸었고 long_chunk는 예측 길이·모델 폭을 함께 바꾸었습니다. 한 파라미터의 독립적 효과로 해석할 수 없습니다.

초기 가중치 스냅샷은 없습니다. HTML 보고서는 실제 최고 검증·마지막 저장 체크포인트의 변화량을 별도로 보여줍니다.

자세한 수치·장면 정정은 [HTML 보고서](../../../docs/mujoco_validation/report.html)를 확인하세요.
