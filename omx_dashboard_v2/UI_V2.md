# OMX Studio v2

기존 `dashboard/`를 보존한 별도 UI입니다. `bash start.sh` 또는 바탕화면의 **OMX 대시보드 v2**로 실행합니다.

- 창 제목 표시줄에 모델 추론 · 데이터 녹화 · 녹화 설정을 통합했습니다. 빈 상단 영역 드래그로 창 이동, 더블클릭으로 최대화/복원, 가장자리 드래그로 크기 조절이 가능합니다. 오른쪽에는 최소화·최대화·닫기 버튼이 있습니다. 녹화 제목 영역을 없애고 카메라와 집계를 바로 표시합니다.
- 추론: 태스크·체크포인트·모델 선택, 자주 쓰는 실행 설정, 접을 수 있는 세부 설정과 로그.
- 녹화: 어두운 실험실 테마, 카메라 나란히 보기·손목 확대·상단 확대, 접을 수 있는 관절 상태와 로그, 항상 보이는 녹화·성공·실패·버리기 버튼.
- 장비 설정과 제어 로직, 모델 실행 명령, 녹화 형식은 기존 코드를 사용합니다.
- 폴더 선택창은 앞서 수정한 Qt 자체 창을 사용합니다.

녹화 설정과 초기 자세는 설치 시 기존 버전에서 복사하며, 이후 이 폴더의 `recorder/config.yaml`, `recorder/init_pose.yaml`에 별도로 저장합니다. 녹화 데이터의 저장 경로는 사용자가 지정한 경로를 그대로 사용합니다.

화면 코드는 `index.html`, `theme.py`, `recorder/ui/studio_window.py`입니다. 원본 녹화 UI의 로직은 상속하고, v2 레이아웃만 `studio_window.py`에서 구성합니다.

창 설정: `omx/dashboard-v2`. 실행 로그: `~/.cache/omx_dashboard_v2.log`.
