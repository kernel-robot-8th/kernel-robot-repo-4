화면 공유 도구에 연결된 화면이 없어 저장된 카메라 영상을 확인했습니다. 초기 세션에는 쌓인 상자, 나중 세션에는 한 개 상자와 바뀐 초기 팔 자세가 관찰됩니다. 이는 테스트 세션의 분포 변화입니다.

검증 설계

학습 녹화 0–7, 검증 8–9, 잠금 테스트 10–14. 각 녹화 전체가 한쪽에만 속하며 미래 action chunk는 에피소드 끝에서 패딩합니다. 정규화 통계는 해당 실험의 학습 녹화에서만 계산합니다. 시드마다 같은 중첩 녹화 부분집합으로 2·4·8개를 비교합니다.

앞 10개 미래 제어 스텝의 검증 MAE로 각 모델 계열의 체크포인트를 고른 뒤 마지막에만 테스트를 엽니다. 지표는 녹화별 평균을 다시 평균하며 bootstrap도 녹화 단위입니다. 관절 명령 오차는 물체 이동 성공률과 다릅니다. 세 개 시드는 물체·실측 데이터 다양성을 추가하지 않습니다.
