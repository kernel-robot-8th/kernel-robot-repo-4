# 팀 담당자와 관제 경계

기준: **2026-10-24 사용자 직접 지정**. 아래 이름과 역할은 기존 담당표보다 우선한다.

| 담당 영역 | 담당자 | 맡는 일 |
|---|---|---|
| 주행 | 김진호 | 주행·경로·정차 등 로봇 주행 기능과 데이터 계약 |
| 로봇팔 | 강민석, 김성아, 허지석 | 팔·그리퍼·상하차 기능과 데이터 계약 |
| 비전 | 손선아, 강건한 | 인식·문제 상황 판별 모델과 비전 데이터 계약 |
| 로봇 수행 관제 | 김지혜 | 작업 요청·진행·결과를 다루는 관제 화면과 연동 |
| 이상 감지 관제 | 강건한 | 문제 상황·알림·판별 근거와 카메라·통신·프로세스 등 상태 관찰 |

로봇 기능 개발과 관제 구현은 구분한다. 로봇 수행 관제가 주행·팔 드라이버를 구현하는 담당을 대신하지 않는다. 비전 담당과 이상 감지 관제는 사람이 겹쳐도 모델·데이터 제공과 관제 화면의 책임을 구분한다.

두 관제는 기존 GUI 셸과 관제 코어를 재사용한다. `gui`·`control_center`는 공유 기술 영역이며 제3의 개인 담당 역할이 아니다. 공통 부분은 영향을 받는 관제 담당끼리 조율하고, 메뉴 결과물의 책임은 해당 메뉴의 관제 담당을 따른다.

메뉴별 책임은 `menu_tree.yaml`의 `control_owner`, 화면 구현은 `screen_owner`, 원천 기능·데이터 계약은 `data_owner`를 따른다. 기존 Station PC 앱인 메뉴 3.7은 로봇팔 담당이 앱을 유지하고 김지혜가 수행 관제의 안내·상태 연결을 맡는다.

Docker·오프라인 번들은 공통 개발 도구다. 주행·팔·비전 패키지는 각 기능 담당이, 수행 관제 연결은 김지혜가, 이상 감지 관제 연결은 강건한이 검증한다. 이 담당 지정만으로 미결 기술 결정이나 실제 실행·배포를 승인한 것으로 보지 않는다.

GitHub CODEOWNERS의 계정과 한글 이름 연결은 실제 계정 확인 후 별도로 적용한다. 이 문서는 사용자에게 받은 한글 담당자를 기록하며 GitHub 계정을 추정하지 않는다.
